FILMROLL 0.5.1 — WINDOWS VERSION
=================================

Thank you for using Filmroll.

Filmroll is free and open-source software intended for photographic
archiving, image review, metadata inspection and related workflows.

INSTALLATION
------------

No installation is required.

1. Extract the complete ZIP archive to a folder of your choice.
2. Keep `Filmroll.exe` and the `filmroll_files` folder together.
3. Run `Filmroll.exe`.

Do not delete, rename or move files inside `filmroll_files` unless you
know that they are not required by Filmroll.
